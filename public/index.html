How it works +
  1. Paste a public Instagram Reel link or upload a saved video under 50 MB and 10 minutes.
  2. The local server extracts audio and sends it to OpenAI for transcription.
  3. Copy or download the text. Temporary media is deleted after processing.

Set up ReelScribe

Your OpenAI API key stays on the local server.

  1. Install Node.js 22 or later, Python 3, and ffmpeg.
  2. In the project folder, run npm install, npm run setup:downloader, and cp .env.example .env.
  3. Open .env and set OPENAI_API_KEY to your OpenAI API key.
  4. Run npm start. Restart the server after changing configuration.

OpenAI API usage is billed to your API account. Instagram may block access to some Reels. You can upload a saved video instead.
